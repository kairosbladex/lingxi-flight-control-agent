# Domain Docs

只有当当前任务依赖领域语义或架构决策时，才去读领域文档。

- 本仓暂无 `CONTEXT.md`。领域语义以 `README.md` 的职责划分与边界说明为准，具体主题读 `docs/` 下对应文档（如 `docs/platform-executor.md`、`docs/route-state-safety.md`、`docs/safety-fast-path.md`）。若将来出现 `CONTEXT-MAP.md`，只按它定位相关上下文。
- 只读影响本次行为或设计的 ADR，不要整目录加载。
- 同会话已读且未变化的内容不重复读取。工具、格式与无关的运行检查不需要领域文档预检。
- 缺失的可选领域文档不构成阻塞，也不需要为它搭脚手架。
- 沿用既有领域名称与真实的代码/接口标识符；只有影响当前决策时才提出矛盾。
- 读到词汇表不等于获得编辑授权。只有任务明确包含领域建模或文档变更时，才更新 `CONTEXT.md` / ADR。

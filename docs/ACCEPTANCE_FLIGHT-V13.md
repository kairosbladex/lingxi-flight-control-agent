| 2.1 飞行控制无权限豁免 | 已验证 | 模拟器急停移除豁免；所有动作确认前复查控制权；平台执行器继续校验权限/owner。只读状态和权限管理不视作飞行动作。 |
| 2.2 围栏前置校验、接口故障降级 | 注入契约已验证，真实数据未接通 | `path_checker(binding, action, parameters, state)` 接收当前绑定和状态，返回 `PathCheck`。移动/指点/环绕预览和确认均检查；blocked 拒绝；不可用时警告并仅跳过围栏，不跳过权限。未实现平台三维碰撞/路径几何引擎，需平台适配器以有限超时提供路径检查结果。 |
| 2.3 自动航线中微操拦截、载荷放行 | 已验证 | running 航线拒绝平移/升降/转向；相机等载荷不受此门禁影响；确认时航线变化使旧卡失效。平台仅在快照提供已识别 route_status 时生效，未知值不能当成验证通过。 |
| 2.4 悬停等价暂停、恢复断点 | 模拟器和 HTTP 已验证 | 精确“悬停”在 running 映射 route_pause，手动映射 emergency_stop，仍确认；模拟器保留主线断点。实际平台断点保存及航线状态映射待联调。 |
| 2.5 参数超限取设备极值并提示 | 部分动作已验证 | 变焦、数字变焦、速度、相对俯仰使用服务端 device_limits；卡片有 requested_parameters/parameters/adjustments。模型先提取原数，不能自行截断。确认时参数表变化拒绝旧卡。协议范围与设备极值取交集，缺设备表且越协议界限时拒绝猜测。坐标、移动距离、航向等不是本次放宽范围。 |
| 3 地面规划、地图标注配置与航线生成 | 不在本仓实施 | 属任务规划 Agent 和平台地图标注；未修改另一 Agent、地图标注库或前端。不得把点/线/面/体策略与任务下发写入飞控上下文。 |
| 4.1/4.3 临时任务替换、主线断点保留 | 模拟器已验证 | 新临时任务覆盖旧临时任务 ID，主线 route_id/断点保留；旧任务完成事件拒绝，当前临时任务完成后可恢复有效主线。真实抢占/完成事件未接通。 |
| 4.2 测绘中断保护 | 模拟器已验证，平台安全阻断 | 单动作卡明确警告成果失效，确认才关闭自动拼图、作废断点，不能恢复；载荷拍照不作废测绘。整份计划涉及测绘中断要求拆成单动作确认。平台缺原子“中断+停拼图+作废断点”契约时拒绝发送。 |
| 4.4 低电量最高优先级、充电恢复原任务 | 模拟事件已验证 | 内部 `apply_task_event` 绑定 task_batch_id，低电量事件丢弃临时任务，阻止覆盖返航，充电后只恢复有效主线；测绘作废或结束全部后不续飞。此方法不暴露给模型/HTTP，未订阅真实平台事件。 |
| 4.5 微操/坐标/环绕/载荷已有能力 | 原契约保留，局部规则增强 | 未改变默认执行器和 59 动作契约。设备挂载/镜头能力仍依赖平台 capabilities；未新增静态标注目标解析器，未宣称完整词典准确率。 |

| 远距离多目标电量追问 | 未实现 | 缺目标解析、距离及剩余航程权威评估接口，不凭空推断可达。 |
| 标注AI到达开启、离开关闭/全局防误关 | 未实现 | 缺作用域算法绑定、到离事件和平台启停契约；未伪造算法正在运行。 |

产品示例对超限同时写了“已拦截”和“按最大值执行”。本次采用正文含义：
参数调整后先展示确认卡，确认后执行有效数值；不声称既拦截又执行。

## 平台接入前的必备工作

1. 平台快照提供并绑定版本：任务类型、航线状态、测绘作废状态、低电量返航、设备参数表。
   当前 `KtdSnapshotProvider` 仍严格遵守旧 v1 schema，不擅自放宽；现有生产快照没有这些新增字段的完整证明。
2. 注入具有超时/资源校验的围栏及碰撞检查服务；本次没有实际平台 URL、没有编造返回 clear。
3. 确定测绘作废的原子接口、临时任务抢占/完成/低电量/充电事件与持久化恢复契约。
4. 补齐喊话/音量/亮度/AI/结束任务的 typed 动作与前端显示、状态订阅及灰化控制。
5. 对并发动作定义接收失败、部分执行、超时、取消、补偿和低电量抢占策略，再实现并发调度。
6. 独立前端验收调整提示、测绘警告及恢复按钮禁用；本次未改前端，后端返回消息不等于 UI 已验收。

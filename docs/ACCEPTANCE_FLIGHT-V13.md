# FLIGHT-V13 飞控规则适配验收

## 第二轮实现与隔离联调 2026-10-21

本轮按用户要求实际修改 Python、Java、Vue 三端并运行隔离联调。下方“需求逐项对照”保留第一轮历史；以下为新增进展，仍不等于 V1.3 全量完成。

- 动作白名单 59→65：新增文本喊话、音量、亮度、AI全局开关、结束当前/全部任务。固定表达走无模型精确解析；模型输出仍须原文依据。权限、预览、确认、幂等与参数调整复用原链。
- 喊话与音量：独立 Java 已实现设备 TTS/音量编译、独立 PSDK 绑定和 services_reply 关联，不调用外部付费 TTS。构建 JAR 和 Agent wheel 间已跑通 HTTP。
- 灯光亮度：Agent 编译到已查证的 `/screen/lighting/control` type=103；音量旧接口 type=109；旧文本 type=201 可能调用外部 TTS，必须声明 LOCAL_SPEAKER_TEXT 能力才可走旧路径。Java 独立服务尚未增加 DRC 灯光传输，不假称两条路径均可用。
- 围栏：查到 `/electronicFence/path-route/with-clean`，已接到标准平台启动装配，预览/确认前都调用。严格核对项目/操作者/原始路径及 segment/invalid，忽略 suggest、不自动绕飞。六向微操使用相对高度；环绕曲线路径和坐标飞行高度基准尚未接通，明确返回 unavailable 并按产品降级。
- 结束任务：已复用 `/portal/task/overTask/safetyCheck` 和 `/portal/task/overTask/{taskId}`，预览及确认前重复安全检查；只允许服务端声明 `task_scope=bound_main_only`，不把原接口误用于含临时子任务的总结束。模拟器支持临时任务结束保留主线、全部结束清断点。
- AI 生命周期：模拟器支持项目算法白名单、全局/标注去重、到达启用、离开仅移除该标注来源；另一标注及全局仍引用则保持。入口支持明确开关。真实平台按算法粒度的启停、标注绑定存储及到离事件尚未实现；查到的 ArAiController/videoDetect 是任务级总开关，不能冒充算法级能力。
- 并发：明确“边向前飞10米边喊话：交通安全”生成两项 parallel 卡，顺序/并发模式进入确认哈希；全部预检成功后两线程提交。失败保留另一项结果，不重试、不伪造回滚；部分成功/未知用例覆盖。仅模拟器和显式支持的 Zhuoyi 执行器启用；不宣称任意自然语言并发拆解全部覆盖。
- 前端：展示调整原值/有效值、测绘等风险、并发部分失败说明、逐项回执；测绘作废恢复按钮禁用，补充临时任务/AI状态。未改变共享入口。
- 平台快照：Python 支持严格类型的可选 V1.3 状态字段，新增字段进入原快照校验与确认绑定；并未伪造实际平台会返回这些字段。Zhuoyi 工具可用性按平台返回过滤，不把所有模拟动作展示成可用。

实际验证：`bash tools/ci/offline_tests.sh` **800/800**，`npm test` **156/156**，`npm run build` 双产物成功；Java `./mvnw -q verify` **122 项、113通过、9跳过、0失败/错误**。跳过外部数据库测试不算通过。Python wheel 构建及三仓 diff 检查通过。

| 2.4 悬停等价暂停、恢复断点 | 模拟器和 HTTP 已验证 | 精确“悬停”在 running 映射 route_pause，手动映射 emergency_stop，仍确认；模拟器保留主线断点。实际平台断点保存及航线状态映射待联调。 |

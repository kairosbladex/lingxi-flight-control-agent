## 一、静态标注 AI 模型配置弹窗与按钮显隐走查 (V1.4 2.1.1)

对前端地图标注编辑面板与 AI 配置对话框进行专项走查，核验结果如下：

| 标注几何类型 | 【AI模型配置】按钮显隐状态 | 规范要求 | 走查结论 | 备注 / 原因 |
| :---: | :---: | :---: | :---: | :--- |
| **点标注 (Point)** | **显示 (Visible)** | 显示 | **PASS** | 支持点目标航点检测算法绑定 |
| **线标注 (Line)** | **显示 (Visible)** | 显示 | **PASS** | 支持单线航线巡检算法绑定 |
| **面标注 (Polygon)** | **显示 (Visible)** | 显示 | **PASS** | 支持面目标正射/网格巡检算法绑定 |
| **体标注 (Volume)** | **隐藏 (Hidden)** | 必须隐藏 | **PASS** | 立体目标不支持自动规划与 AI 算法检测 |

### 弹窗交互与多选复选框规则
1. **多选交互**：点击按钮呼出弹窗，动态拉取当前项目 `state.configured_algorithms` 算法池（如“人员溺水检测”、“烟火识别”、“车辆违停”等），支持多选复选框勾选；
2. **非必填校验**：允许用户不勾选任何算法直接保存，此时该标注作为纯地理目的地处理，不会因空配置阻断保存流程；
3. **前端防越权拦截**：前端若通过非常规手段强行向体标注注入算法列表，底层 API 网关将直接返回 `BODY_ANNOTATION_AI_UNSUPPORTED`（422）硬拦截。
